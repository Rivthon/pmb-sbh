# Sistem Informasi Penerimaan Mahasiswa Baru

Sistem Informasi Penerimaan Mahasiswa Baru adalah aplikasi berbasis web yang memudahkan universitas dalam mengelola proses penerimaan mahasiswa baru. Sistem ini mendukung pengelolaan data calon mahasiswa, verifikasi berkas, serta komunikasi email melalui sistem notifikasi otomatis.

## Persyaratan Sistem

- **PHP versi 8.2 atau di atasnya**  
  [Unduh PHP 8.2](https://windows.php.net/download#php-8.2)
  
- **Composer**  
  [Unduh Composer](https://getcomposer.org/Composer-Setup.exe)

- **Database MySQL**  
  [Unduh MySQL Server](https://dev.mysql.com/downloads/mysql/)

- **Akun SMTP (Google SMTP atau Mailtrap SMTP)**  
  - [Panduan Google SMTP](https://divisidev.com/post/laravel-gmail-smtp)
  - [Panduan Mailtrap SMTP](https://www.giuseppemaccario.com/how-to-send-emails-in-laravel-using-mailtrap/)
